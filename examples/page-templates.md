# Page-type rewrite templates

These are the sentences you ship. Fill brackets with facts. A bracket filled with a hedge **FAILS THE TASK**.

**MUST** classify the string `visitor` before you paste a template into the product.
**MUST** rewrite. Do not soft-wrap a banned phrase into the bracket.
**NEVER** put legal hedges here. Those live only in Terms / Privacy.
**NEVER** stack a second honesty line under the template. One `Checked YYYY-MM-DD · sources below` per section, or none.

Banned families that **MUST NOT** appear in any filled template: may / might / might not, results vary, not guaranteed, for reference only, AI-generated disclaimer spam, 可能 / 或许 / 不确定 / 不保证 / 仅供参考 / 结果因人而异 / 未经验证 / 未经测试 / 不代表.

## 1) AI generator / creative tool landing

**Hero**
```
[ONE LINE: what they get]. [ONE LINE: how fast / what input].
```
Ship: `Your photo. An AI rap video with sound. Pick a scene and generate.`

**Template card**
```
[Name]
[What it includes: length, format, sound]
[Credit cost]
[CTA: Make yours / Generate]
```
The card has no variance line, no "checked again," no AI-disclaimer.

**Primary CTA:** `Generate` / `Make yours`. The button does not apologize.

**Deep help (once, not beside the button)**
- Photo tip, if you have one
- Rights / commercial use → link Terms

## 2) Pricing / credits

```
[Pack name] — [price]
[What it buys, in plain units]
[CTA: Buy credits]
```
Ship: `Starter — $9` / `40 credits. One credit, one render.`

Expiry, region, or tax → one line under the whole grid, and only when it is true. Not under every price. Not a hedge.

## 3) Game wiki codes

**If none**
```
No active [Game] promo codes as of [YYYY-MM-DD].
```

**If some**
```
Active codes · checked [YYYY-MM-DD]
- CODE — reward
How to redeem: [steps]
```

The H1 is the conclusion. It is not "unverified," "not tested," "未经验证," or "未经测试."
Sources: one block at the bottom.

## 4) Checkout

Ship:
```
[What they pay] · [what they get]
I have the rights to this photo. I agree to the Terms.
```

**MUST** keep a single rights / age / Terms consent when you need one.
**NEVER** add a second checkbox about variance, AI failure, "for reference only," or "results may vary."
Refunds and warranties stay in Terms. They do not sit on the pay button.

## 5) Empty states

**No items**
```
No [things] yet.
[One next action]. [One concrete time or cost, if you know it].
```
Ship: `No videos yet.` / `Generate the first one. It takes about a minute.`

**No search hits**
```
No matches for “[query]”.
Try a shorter name.
```

**NEVER** fill an empty state with "might not have synced," "not verified," "for reference only," "可能," "不确定," or "仅供参考." An empty list is a fact plus a next step.

## 6) Error / failure UI

```
[What failed]. [What we did with credits/money]. [What to try next].
```
Ship: `Render failed. We returned the credit. Try again, or use a tighter crop.`

**NEVER:** "Something may have gone wrong in some cases," "success is not guaranteed," "不代表."

## 7) Refuse these fills

If the only draft you have looks like any line below, do not publish it. Rewrite using the template above. Then run FAIL CONDITIONS in `AGENTS.md`.

- Results may vary / results vary / not guaranteed / for reference only
- AI-generated / AI may be wrong / as an AI
- Unverified / not tested / we cannot confirm
- I understand results may vary
- 可能 / 或许 / 不确定 / 不保证 / 仅供参考 / 结果因人而异 / 未经验证 / 未经测试 / 不代表
