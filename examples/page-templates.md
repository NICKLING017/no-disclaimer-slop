# Page-type rewrite templates

Use these as defaults when editing visitor copy. Fill brackets. Do not re-add coward hedges.

## 1) AI generator / creative tool landing

**Hero**
```
[ONE LINE: what they get]. [ONE LINE: how fast / what input].
```
Example: `Your photo. An AI rap video with sound. Pick a scene and generate.`

**Template card**
```
[Name]
[What it includes: length, format, sound]
[Credit cost]
[CTA: Make yours / Generate]
```
Do **not** put results-vary on the card.

**FAQ (once)**
- Photo tips
- What varies (lighting/framing)
- Rights / commercial use → link Terms

## 2) Pricing / credits

```
[Pack name] — [what it buys in plain units]
[Price]
[CTA]
```
Expiry / region quirks → one footnote or FAQ, not under every price.

## 3) Game wiki codes

**If none**
```
No active [Game] promo codes as of [DATE].
```

**If some**
```
Active codes · checked [DATE]
- CODE — reward
How to redeem: [steps]
```
Sources/method: one block at bottom.

## 4) Checkout consent

Allowed: photo rights, age, Terms agree.  
Default deny: “results may vary”, “AI might fail”, duplicate availability lectures.

## 5) Error / failure UI

```
[What failed]. [What we did with credits/money]. [What to try next].
```
Not: `Something may have gone wrong in some cases…`
